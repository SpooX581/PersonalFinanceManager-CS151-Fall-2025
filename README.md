## CS 151 Project 1: Personal Finance Manager

Overview:
A Java-based application to help users manage their personal finances, track expenses, create budgets, and receive financial recommendations.

Design:
The design of our project is that you will be mainly interacting with the User.java. In the User.java, you will be prompted with various instructions to obtain your personal information so that we can create your account. With your account, you will have different types of sections like your credit cards, finance manager, bank account, and loan tracker. For each section there is a specific file/class to implement them individually. Our project is inspired off on Mint and Monarch Money.

Installation Instructions:
You will need an IDE, examples being IntelliJ or VScode, in order to load our project files in. Then, download our project files and then you just need to open them up and then start by interacting in User.java with your terminal!
